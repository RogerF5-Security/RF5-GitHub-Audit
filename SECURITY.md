# Seguridad

Para reportar una vulnerabilidad de RF5 GitHub Audit, utiliza el canal privado del repositorio:

https://github.com/RogerF5-Security/RF5-GitHub-Audit/security/advisories/new

Incluye la versión, los pasos de reproducción y el impacto. Comparte ejemplos sintéticos que no contengan credenciales, valores de secretos ni datos internos.

Los defectos de esta integración se reportan aquí. Las alertas de dependencias y secretos encontradas en otros repositorios deben tratarse con sus respectivos responsables.

La rama principal contiene la versión mantenida.
